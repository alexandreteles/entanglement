# Security Policy

## Supported versions

Only the [latest release](https://github.com/alexandreteles/entanglement/releases/latest)
of Entanglement is supported and receives security fixes. When a new version is
released, all earlier versions immediately become unsupported. Security fixes
are not backported to earlier versions.

Update to the latest release before you check whether a vulnerability still occurs.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/alexandreteles/entanglement/security/advisories/new)
to send a report to the maintainers. Do not report vulnerabilities in public
issues or pull requests.

Include this information in your report:

- The Entanglement version, operating system, and installation method.
- A description of the vulnerability and its security impact.
- Steps to reproduce the problem, including the command and a small source file
  or patch if needed.
- The expected result and the actual result.
- A proposed fix, if you have one.

Remove secrets and personal data from all examples. Keep vulnerability details
private until a fix is available or the maintainers agree to publish the details.
Use the private report to discuss a fix and when to publish the details.
