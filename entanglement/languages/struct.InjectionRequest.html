Fields§

§language: String§range: Range<usize>§guest_ranges: Vec<Range>

The source ranges owned by the injected language. These may leave host expressions between them, such as ${...} in a tagged template.

§priority: i32§inherit_scope: bool§inherit_metrics: bool

Assign injected functions, decisions, and tokens to the host metric context.

§inherit_context: bool

Reuse the host semantic context so names can cross the language boundary.

§share_bindings: bool

Expose top-level injected bindings to the host while keeping guest lookup isolated.

§publish_exports: bool

Keep exports emitted by the injected analyzer in the file-module surface.

§registered_only: bool

Ignore optional language labels unless a registered analyzer matches.

§serialized_bindings: Vec<LocalBinding>

Explicit host bindings serialized into this guest context.
