Expand description

The shared execution graph, including call-site evidence on each edge.

Petgraph provides node access and forward/reverse adjacency. Parallel edges preserve distinct call sites and relation kinds. Unresolved, ambiguous, and virtual references remain in file analyses and do not enter this graph. A node uses the first reported function for each file and start byte. Duplicate edges have equal relation kinds, endpoints, and source ranges.
