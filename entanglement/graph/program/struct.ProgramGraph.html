Struct ProgramGraph 

Source 
pub(crate) struct ProgramGraph<'a> {
    facts: Vec<FileFactsView<'a>>,
    indexes: Arc<ProgramIndexes<'a>>,
}
Expand description

An indexed view of all normalized program facts across analyzed files.

This owns common symbol, scope and binding indexes while borrowing the canonical language facts. Resolver families keep their lookup rules, but share symbol identities, scope selection, path aliases, and call-edge validation.
